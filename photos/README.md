# photos

Put puzzle photos here while you are learning: one snapshot when you want the program to look at the board.

A few sample JPGs in git are fine. Phone pictures are often 2 to 4 MB each. Keep the big pile on the computer, and commit only the shots that document a success or a failure you will want later. Video files (`.mp4`, `.mov`, `.avi`) in this folder are ignored by git. A long video is the wrong tool for the early phases anyway. The everyday update is one still photo.

The reference picture used in the main README lives in [docs/images](../docs/images/), so this folder can stay empty until you take your own.

## Getting a phone photo into the virtual machine

1. Take the photo on your phone.
2. Copy it onto the Windows laptop (a cable, Nearby Share, or any way you already move pictures).
3. Drag it into Ubuntu, or drop it in the shared folder from [the setup guide](../docs/setup.md), then copy it into this folder.

Helpful names look like `section-A-001.jpg`. Section letter, then a number, so the files sort themselves.

Later, the phone web page will accept the upload directly. Copying files by hand is the path until that page exists. The puzzle may be out of reach of a webcam, which is why the phone photo is the real input.
